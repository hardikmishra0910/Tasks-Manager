# 📝 Task Manager System

A modern **Task Management System** built with **React, TypeScript, Tailwind CSS, and Vite**.  
It allows users to create, update, and organize tasks with priorities, statuses, and color-coded categories for better productivity.

---

## 🚀 Features
- ✅ Add, edit, and delete tasks  
- 🎨 Color-coded task organization  
- 🔖 Priority & status badges  
- 🗂️ Task detail modal with extended info  
- ⚡ Fast and optimized with Vite + TypeScript  
- 🎨 Styled with Tailwind CSS & Shadcn UI components  

---

## 🛠️ Tech Stack
- **Frontend:** React + TypeScript + Vite  
- **Styling:** Tailwind CSS, Shadcn UI  
- **State Management:** React hooks & context  
- **Build Tool:** Vite
